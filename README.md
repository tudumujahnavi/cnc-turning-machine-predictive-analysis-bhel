# CNC Turning Machine - Predictive Maintenance

BHEL internship group project.

## How to Run
```
pip install pandas scikit-learn streamlit numpy matplotlib joblib
cd project
streamlit run app.py
```

## Files
- `app.py` - Streamlit dashboard
- `main.py` - Training and data pipeline  
- `model.py` - Model functions

## Disclaimer
Academic demonstration project for internship purposes only. No proprietary BHEL data, systems, or confidential information were used.
